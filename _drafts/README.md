# Drafts Workflow

Use this folder for new project or writeup drafts before publishing them to the website.

## Files

- TEMPLATE-writeup.md — starter template for new security writeups
- TEMPLATE-project.md — starter template for new project pages

## Recommended flow

1. Copy the template you need.
2. Rename it using a descriptive filename.
3. Fill in the front matter and content.
4. Move the file into the appropriate collection folder when ready:
   - _writeups/ for writeups
   - _projects/ for projects
5. Set the review status and publish once ready.

## Front matter conventions

- Use `published: false` while working locally.
- Remove it or change it to `published: true` before publishing.
- Keep `layout` aligned with the collection type.
- Add `featured: true` only on the main project you want highlighted.
