## Summary

This room introduced foundational cybersecurity concepts and helped build a stronger understanding of how security roles, attacker behavior, and defensive controls fit together in a real environment.

## Key Takeaways

- Cybersecurity covers people, processes, and technology
- Threat actors use reconnaissance, exploitation, and persistence techniques
- Defenders rely on monitoring, prevention, and response workflows
- Security is as much about process and awareness as it is about tools

## Notes

The room was useful as a starting point for understanding the broader landscape of security and how different roles contribute to a defensive program. It also helped frame how detection engineering and SOC work fit into the larger picture.
