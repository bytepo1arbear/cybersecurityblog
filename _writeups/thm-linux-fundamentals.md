## Summary

The room reviewed the structure and behavior of Linux systems, including the file system, key user concepts, and permission models. It built a stronger basis for system investigation and defensive analysis.

## Main Concepts

- Filesystem hierarchy and directory roles
- User and group permissions
- Common commands for file and process inspection
- Basic privilege boundaries and risk surfaces

## Why It Matters

Linux systems are widely used in enterprise and lab environments, so understanding basic command-line behavior and file permissions is critical for both offensive testing and defensive monitoring.

## Notes

This challenge reinforced the importance of learning the basics thoroughly, especially when responding to suspicious activity or validating privilege boundaries on Linux hosts.
